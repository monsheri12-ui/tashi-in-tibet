# Таши в Тибете

Некоммерческая обучающая игра о тибетском языке в повседневной жизни. Играть: https://foxsaywawa.tilda.ws/tashi-in-tibet

Открыть игру отдельно: https://monsheri12-ui.github.io/tashi-in-tibet/

Версия 1.0.6. Основная игра включает русский и английский интерфейсы, сохраняет прогресс и предлагает три уровня погружения в тибетский. На телефоне крупную сцену можно сдвигать вбок или переключить в общий вид; задания находятся ниже иллюстрации.

В меню можно экспортировать сохранение в файл и импортировать его на другом устройстве или при переходе между отдельной игрой и встроенной версией.

Публикация использует неизменную базу 1.0.2 и три проверенных архива релиза 1.0.6. SHA-256 закреплены в `.github/workflows/pages.yml`; перед публикацией проверяются все 491 ресурса. Лицензии ресурсов входят в сборку.

Для повторной публикации откройте Actions → Publish Tashi to GitHub Pages → Run workflow и выберите ветку `main`. Для встраивания на сайт используется адрес опубликованной игры в iframe.

Панель разработчика включена исключительно в независимом проекте tashi-in-tibet-dev. Тильда и эта основная сборка не содержат её контролов.
