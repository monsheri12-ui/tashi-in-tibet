# Таши в Тибете

Некоммерческая браузерная игра для изучения тибетского языка.

Играть на сайте «Лисья нора»: https://foxsaywawa.tilda.ws/tashi-in-tibet

Открыть игру отдельно: https://monsheri12-ui.github.io/tashi-in-tibet/

Игра сохраняет прогресс в браузере. В меню можно экспортировать сохранение в файл и импортировать его на другом устройстве или при переходе между отдельной игрой и встроенной версией.

## Публикация

Ресурсы игры находятся в архиве `tashi-in-tibet.zip` релиза `v1.0.2`; исправления интерфейса и анимаций — в `tashi-update.zip` релиза `v1.0.4`. GitHub Actions проверяет контрольную сумму архива и публикует игровые HTML-файлы, папки `assets` и `licenses` через GitHub Pages.

Для повторной публикации откройте Actions → Publish Tashi to GitHub Pages → Run workflow и выберите ветку `main`. При обновлении сборки нужно указать новый архив релиза и его SHA-256 в `.github/workflows/pages.yml`.

Для встраивания на сайт используется адрес опубликованной игры в iframe.

Условия использования включённых материалов и сведения об источниках находятся в папке `licenses` внутри архива.
