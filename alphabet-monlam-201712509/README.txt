Тренажёр тибетского алфавита — 500 слов, два голоса.

Обычная озвучка и учебные схемы сохранены. Медленный темп (0,8) подготовлен заранее из тех же исходных WAV. Плеер воспроизводит оба варианта со скоростью 1,0, без изменения темпа средствами браузера.

Исходная проблема воспроизводилась только в медленном темпе на странице. Пользователь подтвердил, что WAV, оба обычных MP3 и новый заранее замедленный пример མཆོད་པ་ звучат без писка.

Файлы обычного темпа: audio/, spelling/. Замедленные файлы: audio-slow/, spelling-slow/. Во время воспроизведения используются статические записи; запросов к сервису синтеза нет.

Проверено: все 2286 новых аудиофайлов декодируются; сборка 500 слов и 150 форм с огласовками для обоих голосов; раздельный кэш темпов; отмена устаревшей загрузки; переключение темпа и голоса; сохранение ключа прогресса. Автоматические проверки не являются экспертной проверкой произношения каждого звука.
